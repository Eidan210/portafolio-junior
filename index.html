01 — Sobre mí

Formación con rigor de entorno real

Mi perfil se construyó dentro de Campuslands, un programa intensivo donde cada módulo se aprueba entregando software que funciona, no solo teoría.

Soy desarrollador de software en formación, con experiencia en el desarrollo de aplicaciones y proyectos utilizando tecnologías como Python, Java, JavaScript, HTML, CSS y SQL. Tengo conocimientos en bases de datos, APIs, desarrollo frontend y backend, además de metodologías ágiles y trabajo colaborativo.

Me caracterizo por ser una persona responsable, autodidacta y orientada a la resolución de problemas. Disfruto aprender nuevas tecnologías, enfrentar desafíos y encontrar soluciones eficientes a diferentes necesidades.

Mi objetivo Seguir creciendo como desarrollador, participar en proyectos desafiantes y aportar mis conocimientos mientras continúo desarrollando nuevas habilidades profesionales.

Aprendizaje basado en proyectos

Cada tema se cierra construyendo una aplicación completa y funcional. La práctica sobre simulaciones de entornos reales es la base de todo lo que aparece en este portafolio.

Control de versiones disciplinado

Git y GitHub como flujo de trabajo diario, no como trámite final: commits descriptivos, historial trazable y un repositorio por entregable desde el primer módulo.

Iteración y mejora continua

Refactorizo lo que ya funciona para que funcione mejor. Proyectos como CampusTech v2.0 nacen de revisar una primera versión y reconstruirla de forma modular.
